## Protocole (adapté pour Hermès / delegate_task)

### SEO vs GEO
| Aspect | SEO | GEO |
|--------|-----|-----|
| Goal | Rank #1 in Google | Be cited in AI responses |
| Platform | Google, Bing | ChatGPT, Claude, Perplexity |
| Metrics | Rankings, CTR | Citation rate, appearances |
| Focus | Keywords, backlinks | Entities, data, credentials |

### Content qui est cité par IA
| Element | Pourquoi l'IA le cite |
|---------|----------------------|
| Original statistics | Données uniques |
| Expert quotes | Autorité |
| Clear definitions | Extractable |
| Step-by-step guides | Utile |
| Comparison tables | Structuré |

### E-E-A-T Framework
- **Experience** : Connaissance directe, histoires réelles
- **Expertise** : Titres, certifications
- **Authoritativeness** : Backlinks, mentions, reconnaissance
- **Trustworthiness** : HTTPS, transparence, reviews

### Checklists
**Technical SEO :**
- [ ] XML sitemap soumis
- [ ] robots.txt configuré
- [ ] Canonical tags corrects
- [ ] HTTPS activé
- [ ] Mobile-friendly
- [ ] Core Web Vitals passant
- [ ] Schema markup valide

**Content SEO :**
- [ ] Title tags optimisés (50-60 chars)
- [ ] Meta descriptions (150-160 chars)
- [ ] Hierarchy H1-H6 correcte
- [ ] Structure de linking interne
- [ ] Image alt texts

**GEO :**
- [ ] Sections FAQ présentes
- [ ] Credentials de l'auteur visibles
- [ ] Statistiques avec sources
- [ ] Définitions claires
- [ ] Citations d'experts attribuées
- [ ] Timestamps "Last updated"

## Limites
- Ne pas faire de triche SEO (keyword stuffing, link schemes) — pénalisé par Google
- Ne pas ignorer le contenu utilisateur au profit des techniques
